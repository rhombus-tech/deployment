# 💎 FRAC Prover Desktop App

## Beautiful, effortless proving for everyone

### Features:
- ✨ One-click install
- 🚀 Auto-starts on boot
- 📊 Real-time earnings display
- 🎨 Beautiful modern UI
- 💤 Runs silently in background
- 🎮 Auto-pause for gaming
- 🔔 Earnings notifications
- 📱 Mobile-like simplicity

### Tech Stack:
- **Tauri** (Rust + Web) - Small, fast, secure
- **React** - Beautiful responsive UI
- **TailwindCSS** - Modern styling
- **Lucide Icons** - Clean iconography

### Bundle Size:
- Windows: ~8MB
- Mac: ~6MB
- Linux: ~7MB

(vs Electron which would be 100MB+)
