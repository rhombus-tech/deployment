## 🚀 Quick Start

1. **Start the demo server:**
   ```bash
   python3 server.py
   ```

2. **Open your browser:**
   - Automatically opens at `http://localhost:8080`
   - Or manually navigate to the URL

3. **Interact with the demo:**
   - Click "Generate Proof" to see the proving process
   - Click "Run Benchmark" to test performance
   - Click "Verify Proof" to validate cryptographic correctness
